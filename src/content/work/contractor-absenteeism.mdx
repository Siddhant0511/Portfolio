export const payday = (() => {
  // Points read from the report's day-of-month figure; missing days linearly interpolated.
  const known = { 1: 25.0, 5: 24.5, 8: 24.8, 10: 25.2, 12: 26.0, 14: 28.5, 15: 27.5, 17: 27.0, 20: 27.7, 21: 29.1, 22: 28.0, 23: 27.3, 24: 25.5, 25: 23.0, 26: 21.5, 27: 22.0, 28: 22.5, 29: 22.0, 30: 21.4, 31: 22.5 };
  const days = Object.keys(known).map(Number);
  return Array.from({ length: 31 }, (_, i) => {
    const d = i + 1;
    if (known[d] !== undefined) return known[d];
    const lo = Math.max(...days.filter((k) => k < d));
    const hi = Math.min(...days.filter((k) => k > d));
    return known[lo] + ((known[hi] - known[lo]) * (d - lo)) / (hi - lo);
  });
})();

## The problem

Workforce stability decides how well an assembly line runs. At the Alwar plant, the contractor workforce had a **76% headline attrition rate**: in effect, the entire contractor base turned over every 16 months.

Nobody could see why, because the data was unusable. Attendance for **8,387 contractor employees** lived in **2,530 Excel files**, kept by more than 15 vendors, each in its own format. Absenteeism was treated as an administrative number to be filed, not as an operational risk to be managed.

The thesis I set out to test: **absenteeism is a leading indicator**. If it rises before people leave, it can warn HR while there is still time to act.

## Building the dataset

Manual consolidation was never realistic. I wrote a Python pipeline to do it, and put a **locally hosted LLM** inside it. That was a practical choice, not an experiment: the files were too many to review by hand, and too confidential to send to any cloud service. Running the model on the laptop meant no employee data left the machine, and the pipeline worked without the plant's internet.

## The tenure paradox

Tenure turned out to be the strongest single predictor of absence, with a correlation of **-0.460**. New hires in their first three months were absent **53.96%** of the time, nearly three times the rate of anyone past six months.

## The attrition illusion

HR had treated a resignation as a sudden event. The data said otherwise. In the weeks before leaving, a worker's absenteeism climbed from the active baseline of **20.7%** to **38.5%**, an 87% jump.

<Callout>Resignations are not sudden. Absence climbs 87% first, which makes it a warning signal HR can act on.</Callout>

That turns absenteeism from a lagging admin metric into an early-warning system: a measurable sign of quiet quitting, weeks before the paperwork.

## Festivals, harvests and heat

External life shaped attendance more than working conditions did. Eid and Holi drove the biggest spikes, and the Rabi harvest pulled workers back to their fields. Two findings ran against intuition: absence **fell** during Diwali, and it fell during extreme heat above 43°C, which suggests workers preferred the air-cooled plant floor to the outdoors.

## What I recommended

The findings pointed to one place to spend effort: the first 90 days, with vendors held accountable for them.

## Impact

Contractor absenteeism went from an opaque administrative burden to something HR can predict. The pipeline turned over a million historical records into one dataset, identified the exact high-risk group, and showed that a spike in absence reliably comes before an exit.

The First 90 Days strategy aims straight at the root cause of the 76% attrition rate, with a quantified path to recovering thousands of lost working days and steadier production lines.
